# KarolaFlow – DCSA Track & Trace Specification

This repository contains the DCSA Track & Trace API specification (v1.5), used in the KarolaFlow project – a container logistics automation system.

## Included

- DCSA TNT v1.5 OpenAPI YAML file

## Source

- https://dcsa.org/standards/
- https://github.com/dcsaorg

## Purpose

This specification is used as a basis for transforming and standardizing container tracking data across multiple shipping lines in accordance with DCSA event models.
